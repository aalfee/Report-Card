# Walker App Backend

This backend provides:
- email/password login for walker accounts
- secure JWT authentication
- walk session ingestion (`/api/walks`)
- client report retrieval (`/api/reports/clients/:clientEmail`)

## Setup

1. `cd backend`
2. `npm install`
3. Copy `.env.example` to `.env`
4. Fill the values:
   - `JWT_SECRET`
   - `ADMIN_SECRET`
   - `CLIENT_API_KEY`
   - optionally `WORKOS_CLIENT_ID`, `WORKOS_API_KEY`, `WORKOS_AUDIENCE`, `WORKOS_DOMAIN`
5. `npm start`

### Supabase migration (recommended for permanent storage)

1. Create a Supabase project (https://app.supabase.com).
2. Add environment variables in `.env` (or Vercel):
   - `SUPABASE_URL`
   - `SUPABASE_KEY` (service_role key)
3. In Supabase SQL editor, run:

```sql
create table if not exists users (
  id bigint generated by default as identity primary key,
  email text not null unique,
  password_hash text not null,
  name text,
  role text not null default 'walker',
  client_email text,
  created_at timestamptz not null default now()
);

create table if not exists walks (
  id bigint generated by default as identity primary key,
  walker_id bigint references users(id),
  client_email text,
  start_time timestamptz not null,
  end_time timestamptz,
  duration_minutes integer,
  distance_meters integer,
  route_json jsonb,
  events_json jsonb,
  poop_count integer default 0,
  pee_count integer default 0,
  notes text,
  created_at timestamptz not null default now()
);
```

4. Deploy or restart backend.

## App configuration

- In `walker-app/src/api.js`, replace `http://<YOUR_BACKEND_HOST>:4000` with your backend URL.
- For local device testing, use your computer IP address: `http://192.168.x.x:4000`.

## API endpoints

### POST /api/auth/register-walker
Body:
```json
{
  "adminSecret": "<ADMIN_SECRET>",
  "email": "walker@example.com",
  "password": "Secret123!",
  "name": "Walker Name",
  "clientEmail": "owner@example.com"
}
```

### POST /api/auth/login
Body:
```json
{
  "email": "walker@example.com",
  "password": "Secret123!"
}
```
Response includes a JWT token.

### POST /api/walks
Headers:
- `Authorization: Bearer <token>`

Body:
```json
{
  "start_time": "2026-04-02T10:00:00Z",
  "end_time": "2026-04-02T10:30:00Z",
  "duration_minutes": 30,
  "client_email": "owner@example.com",
  "route": [{ "lat": 12.34, "lng": 56.78 }],
  "poop_count": 1,
  "pee_count": 2,
  "notes": "Good walk"
}
```

### GET /api/walks
Requires authentication. Returns all walks for the logged-in walker.

### GET /api/reports/clients/:clientEmail
Headers:
- `x-client-key: <CLIENT_API_KEY>`

Returns walk report data for the specified client email.

## Notes

- Hostinger Website Builder cannot host this backend directly.
- Deploy this service to an external host, then point the mobile app to the new API base URL.
- The WorkOS variables are included so you can add WorkOS-based login later.
