# Document Governance Policy

Every document follows a lifecycle: Draft → Review → Approved → Published → Archived.

## Security and visibility

- Public documents are safe for general distribution.
- Member documents are available only to authenticated members.
- Staff and admin documents are restricted to internal teams.

## Naming and metadata

- Use lowercase kebab-case for file names.
- Give each document a stable, unique ID.
- Keep metadata in `data/documents.json` and use it as the source of truth.

## Review cadence

- Review active institutional documents at least annually.
- Never publish confidential content such as personal data, passwords, or secret keys.
